Language Documentation

Introduction

This tool allows you to write simple programs in a custom language and transpile them into equivalent C++ code. The transpiled C++ code can then be compiled and run using a standard C++ compiler (like g++).

Language Syntax

The simple language supports basic variable declarations, printing values, direct C++ code injection, function definitions, calls and return statements, and now arithmetic operations. Each statement now optionally ends with a semicolon (;). Newlines are implicitly treated as statement separators.

  • Variable Declaration/Assignment: identifier [ : type ] = value

    Declares or assigns a value to a variable. The type is inferred from the assigned value if no explicit type is provided (e.g., myVar = 10). Optionally, you can explicitly declare the variable's type using a colon (:) followed by the type keyword (int, float, string, or bool). If an explicit type is given, the assigned value's type must be compatible with the declared type.

    The value can be a numeric literal, a string literal (enclosed in double quotes), a boolean literal (true or false), another already declared variable, the result of a function call, or an arithmetic expression.

    Example:

    myNumber = 100             // Type inferred as int
greeting:string = "Hello"  // Explicit string type
isActive:bool = true       // Explicit boolean type
version:float = 1.25       // Explicit float type
newVar = myNumber;
sum = add(10, 20)
calculatedValue:int = (5 + 3) * 2 / 4 - 1 // Result must be compatible with int
  • Print Statement: PRINT value

    Prints the value to the console. The value can be a numeric literal, a string literal (enclosed in double quotes), a boolean literal (true or false), a variable, the result of a function call, or an arithmetic expression.

    Example:

    PRINT 42
PRINT myNumber
PRINT "Done!"
PRINT isActive;
PRINT calculateArea(5, 10)
PRINT 10 * (5 + 2)
  • Raw C++ Injection: _cpp_("your C++ code here")

    Allows you to inject raw C++ code directly into the transpiled output. The content within the double quotes will be placed as-is into the main function or a custom function body of the generated C++ file. Ensure all necessary C++ syntax, including semicolons for C++ statements, is present within the string.

    Example:

    _cpp_("std::cout << \"Hello from direct C++!\" << std::endl;")
_cpp_("int localVariable = 50;")
_cpp_("if (localVariable > 10) { std::cout << \"Local var is large.\" << std::endl; }")
  • Function Definition: function functionName([param: type], ...) [ : returnType ] ... end

    Defines a new function. Functions are declared with the function keyword, followed by the function name, and then a list of parameters in parentheses. Each parameter can optionally specify its type (e.g., param:int). If a parameter type is omitted, it defaults to int. Optionally, the function's return type can be specified after the parameters using a colon (:) followed by the type keyword. If no return type is specified, it defaults to void if no return statements are present, or inferred from the first return statement's value.

    The function body contains statements, and it must be closed with the end keyword.

    Example:

    function displayMessage(msg:string, count:int)
  PRINT "--- Function Start ---"
  PRINT msg
  counter = count
  PRINT counter
  _cpp_("std::cout << \"Message displayed \" << count << \" times.\\n\";")
  PRINT "--- Function End ---"
end

function add(a:int, b:int): int
  result = a + b
  return result
end

function getGreeting(): string
  return "Hello there!"
end
  • Function Call: functionName(arg1, arg2, ...)

    Calls a defined function. Arguments can be numeric literals, string literals, boolean literals, variables, or expressions. Function calls can be standalone statements or used within PRINT statements or variable assignments.

    Example:

    callMe(10)
myString = "Test"
processData(myNumber, myString, true)
result = calculate(10 + 5, 20 / 4)
  • Return Statement: return value

    Used inside a function to return a value. If the function has an explicit return type, the returned value's type must be compatible. If no explicit return type is given, the function's return type in C++ is inferred from the type of the value returned by the first return statement encountered in its body. All subsequent return statements in the same function must return values of compatible types. If no return statement is present in a function without an explicit return type, the function will have a void return type in C++.

    Example:

    function add(a, b)
  result = a + b
  return result
end

function getGreeting()
  return "Hello there!"
end

function isPositive(num)
  IF num > 0 THEN
    return true
  ELSE
    return false
  END
end
  • Arithmetic Operations: +, -, *, /, ( )

    Supports basic arithmetic operations with standard operator precedence (multiplication/division before addition/subtraction) and parentheses for grouping. The + operator can also be used for string concatenation if both operands are strings. Other operators (-, *, /) only work with numbers.

    Example:

    x = 10
y = 5
sum = x + y          // 15
diff = x - y         // 5
prod = x * y         // 50
quot = x / y         // 2 (integer division)
complex = (x + y) * 2 - (prod / 10) // (10+5)*2 - (50/10) = 15*2 - 5 = 25
myString = "Hello, " + "world!" // String concatenation

How to Use

  1. Enter your simple language code into the "Simple Language Code" text area on the left.
  2. Click the "Transpile to C++" button.
  3. The equivalent C++ code will appear in the "Transpiled C++ Code" text area on the right.
  4. You can then copy the C++ code and compile it with any C++ compiler (e.g., g++ your_code.cpp -o your_program and then ./your_program).

Quick Example

quantity = 5
price = 10
totalCost = quantity * price // 50
message:string = "Program finished!" // Explicit string
isComplete:bool = true

function calculateAndPrint(val1:int, val2:float): float
  localSum:int = val1 + val2 // Explicit int
  anotherVar:float = val2 * 2.5 // Explicit float, mixes with int
  PRINT "--- Inside calculateAndPrint ---"
  PRINT localSum
  PRINT anotherVar
  _cpp_("std::cout << \"Calculations done in C++.\\n\";")
  return localSum + (anotherVar / 4)
end

function greet(name:string): string
  return "Hello, " + name + "!"
end

_cpp_("std::cout << \"Initiating main program...\" << std::endl;")
PRINT totalCost
PRINT price
PRINT message
PRINT isComplete;
resultOfCalc = calculateAndPrint(100, 200.5)
PRINT "Result of calculation function:"
PRINT resultOfCalc
myGreeting = greet("World")
PRINT myGreeting
_cpp_("std::cout << \"Main program fully initialized.\" << std::endl;")
